# Brody

The original mascot: platinum surfer mullet, coral sweatband with a mint stripe, white shield shades with sunset lenses, chevron moustache, puka necklace with a gold shark tooth, flamingo shirt, no tattoos.

- `brody-master.png` is the identity reference. Pass it in whenever you generate a new expression.
- `mood-prompts.txt` holds the expression prompt for each sticker.
- Stickers are generated on flat `#00FF00`, keyed, and fitted to 512x512.

To add a mood: append a case to `Mood` (never renumber) and add a `bro-<slug>` image set.

Fonts: Anton (OFL) and Yellowtail (Apache 2.0). Sounds come from `Scripts/make_sounds.py`.
